# Acoustic Response Machine

Experimental audiovisual installation.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173 — click canvas to enable mic. Sound grows the structure.

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Dev server |
| `npm run build` | Typecheck + production build |
| `npm test` | Typecheck only |
