# Growth Rules (Phase 4)

Artistic mappings — not physical/scientific claims.

| Acoustic cue | Structural effect |
|--------------|-------------------|
| ENERGY / RMS | Growth length, presence, branch likelihood |
| ONSET | Strongest trigger for new segments / branches |
| SPECTRAL CENTROID | Angular variation (high → sharper turns) |
| HARMONICITY | Coherence (high → less turn) |
| NOISE / ZCR | Irregularity / branch variation |
| SILENCE | No new growth; slow decay of unprotected leaves |

## Behavior

- **No permanent trunk / UP axis.** Root is origin only.
- **Event-driven:** IMPACT/TRANSIENT fire immediately; SUSTAIN uses an energy budget (not every frame).
- **Frontier:** multiple active endpoints; each event selects one stochastically.
- **Direction:** previous angle + bounded acoustic-weighted random turn.
- **Branches:** irregular (not symmetric Y-splits).
- **Loops:** rare connections to nearby existing nodes.
- Existing geometry persists; only new segments are added.
