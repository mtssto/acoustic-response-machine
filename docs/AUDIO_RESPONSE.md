# Machine Audio Response (Phase 9)

The visual structure drives a short synthesizer reply (call–response).

## Mapping (artistic)

| Source | Synth param |
|--------|-------------|
| density / junctions | base frequency |
| stability / noisiness | harmonicity vs texture |
| structural direction | stereo pan |
| growth / markers / action | duration |
| machine energy | amplitude |

## Behavior

- Triggers on IMPACT / TRANSIENT / strong BRANCH·CREATE / high memory influence
- Short envelopes (~0.1–0.45s) + cooldown (~1.2s) to limit mic feedback
- Partial stack + optional noise texture
- Key `R` toggles response on/off

Not a continuous drone, not a mic echo — a discrete machine reply derived from structure.
